# COFFEE HOUSE – Design Specification

## 1. Descripción del proyecto
COFFEE HOUSE es una página web de una cafetería especializada en café artesanal y repostería. Su objetivo es mostrar sus productos y transmitir una imagen acogedora y elegante.

## 2. Estilo visual
- Diseño moderno, sencillo y minimalista.
- Inspiración en cafeterías artesanales.
- Distribución mediante Flexbox.
- Diseño adaptable a móviles y ordenadores.

## 3. Paleta de colores
- Marrón principal: `#3b2418`
- Marrón secundario: `#8b5e3c`
- Fondo crema: `#f5efe6`
- Texto: `#2b211c`
- Blanco: `#ffffff`

## 4. Tipografía
Se utiliza la fuente Poppins importada desde Google Fonts.

## 5. Estructura de la página
- Header: nombre y eslogan de la cafetería.
- Navegación: enlaces a las diferentes secciones.
- Hero: imagen principal, mensaje de bienvenida y botón.
- Nosotros: presentación de la cafetería.
- Carta: tarjetas con productos y precios.
- Aside: información adicional.
- Footer: redes sociales y derechos reservados.

## 6. Componentes y efectos
- Menú interactivo con efecto hover.
- Tarjetas de productos con sombras y movimiento.
- Botones con transiciones de color.
- Botón flotante para volver al inicio.
- Iconos de redes sociales mediante Font Awesome.

## 7. Diseño responsive
Se utiliza una media query con un punto de ruptura de 700px para adaptar la navegación, las tarjetas y las secciones a dispositivos móviles.

## 8. Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome
- GitHub Pages para la publicación.
